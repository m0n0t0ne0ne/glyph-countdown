One page for everything that happens when time's up, and a new stutter sync that jerks the animation in time with your alarm sound.

### New
- **Time's up page**: the animation, sound, sync, dimming and vibrate settings now live together on one page, with a preview pinned at the top that plays your choices with the real sound, exactly as the alarm will. Open it from *Settings › Time's up* or the shortcut under the dial. Changes save as you make them, and picking a sound plays it with the animation.
- **Stutter sync**: with *Sync with alarm sound* on, the animation still plays through in full and starts with the sound each loop, but on every note it jerks: one note snaps it back in two quick steps, the next rewinds it smoothly, and each holds for a moment before carrying on.
- **Dim with notes** switch: turn the blinking off for stutter only, at full brightness.
- **Dim level** slider: choose how dark the matrix dims between notes, from subtle to deep.

### Changed
- **Settings are shorter**: one *Time's up* row with a summary replaces the separate Time's up animation, Sync, Alarm sound and Vibrate settings.
- The timer screen's alarm sound row is now a **Time's up shortcut** showing your animation and sound.
- Time's-up animations run at 25 frames a second so the stutter reads cleanly.

### Install
Download the APK below and open it on your phone; it installs over earlier versions and keeps your settings. Requires Android 13+.
