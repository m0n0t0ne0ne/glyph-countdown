Flip to start works again, and synced animations now blink with your alarm sound.

### Fixed
- **Flip to start**: placing the phone face-down with the app open started the timer, but the new "Only when screen is off" setting kept the Glyph Matrix dark because the screen was still on. Face-down now counts as screen off, so the countdown appears on the back straight away.

### Changed
- **Flip to start is always on**, as it was originally, and is no longer a setting.
- **Sync with alarm sound blinks**: instead of a steady glow, the matrix now steps through brightness levels with each note: a full flash with sparks around the edge, two dimmer steps, then a brief dark gap just before the next note. Successive notes flash at different strengths, so it reads as blinking in rhythm with the sound.

### Install
Download the APK below and open it on your phone; it installs over 1.0 or 1.1 and keeps your settings. Requires Android 13+.
