The Glyph Matrix stays lit after flip to start and through the whole alarm.

### Fixed
- **Matrix went dark after flip to start**: a second after flipping, the matrix turned off for about 5 seconds, then came back. Your hand letting go and the phone settling looked like movement, so the app briefly decided it wasn't on a table. It now waits for the phone to settle before judging, and stays lit.
- **Time's-up animation turned off after a few seconds**: the alarm's own vibration shook the phone on the table, which looked like it being moved, so the matrix went dark while the alarm was still ringing. The vibration no longer counts as movement, so the animation stays lit for as long as the alarm rings.
  - Picking the phone up still counts, by the change in its angle.
