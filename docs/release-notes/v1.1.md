The Glyph Matrix gets time's-up animations that keep time with your alarm sound, and goes dark while you're using the phone.

### New
- **Time's-up animations**: choose what the Glyph Matrix shows when the timer ends, in *Settings › Time's up animation*. Keep the flashing ring (Default), or pick one of ten looping animations:
  - Contour, Kaleido, Tide, Pulse, Lattice, Moiré, Weave, Glyph and Knot
  - Totem, which folds up like origami and opens back out
  - Every option has a live preview, and all of them work on the Phone (3) and Phone (4a) Pro matrices.
- **Sync with alarm sound**: the animation is paced to the alarm sound you picked, so each loop starts with the sound, and it flashes, with sparks around the edge, on every note. Works with the Nothing and alarm sounds; on by default and can be switched off.
- **Only when screen is off**: the Glyph Matrix goes dark while the screen is on, and lights again when it turns off. On by default; switch it off to keep the matrix lit all the time, as in 1.0.

### Changed
- The alarm sound now plays through Android's media player so the animation can follow it. If a sound can't be opened that way, it falls back to the previous player.

### Install
Download the APK below and open it on your phone; it installs over 1.0 and keeps your settings. Requires Android 13+.
