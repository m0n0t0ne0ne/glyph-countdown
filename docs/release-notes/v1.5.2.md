A new **00** button clears the timer back to 00:00:00 in one tap.

### New
- **Zero out the timer**: a round **00** button now sits to the right of Start. Tap it while setting a time and the hours, minutes and seconds all go back to zero, so you can dial in a new time from scratch instead of winding each unit down.
  - It only works while you're setting the time. While a countdown is running or paused it's greyed out; Reset still takes you back to the time you set.
  - With the dial at zero, Start and **00** grey out until you drag in a time.

### Install
Download the APK below and open it on your phone; it installs over earlier versions and keeps your settings. Requires Android 13+.
