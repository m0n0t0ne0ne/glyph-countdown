Double-tap to dismiss works on a table again.

### Fixed
- **Double-tap stopped working on a table in 1.4.6**: now that the time's-up animation stays lit for the whole alarm, drawing it kept the app's main thread busy, and double-tap was listening for taps on that same thread. A tap on a table lasts only a few milliseconds, so readings held up behind the animation could miss it. Double-tap now listens on a thread of its own, and times each reading by when it was measured, so the animation can't get in the way.
