The time's-up animation stays lit on the table, with or without vibration.

### Fixed
- **Time's-up animation still turned off after a few seconds**: 1.4.5 only covered it while the alarm vibrated. The real cause was double-tap to dismiss: when the alarm starts it reads the motion sensor at full speed, which also sped up the readings the app uses to tell where the phone is. Flooded with readings, it could only look back about a second, never long enough to see the phone lying still, so it decided the phone had been picked up and turned the matrix off. It now keeps the same steady pace however fast readings arrive.
  - While the alarm rings, a loud speaker shaking the phone on the table doesn't count as movement either. Picking the phone up still counts.
